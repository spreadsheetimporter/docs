# Installing the Community Edition

The maintained UI5 Spreadsheet Importer is available from the public npm registry. Version 2.5.0 includes production use under the Apache License 2.0.

```sh
npm install --save-exact ui5-cc-spreadsheetimporter@2.5.0
```

Continue with the [installation and namespace setup](../GettingStarted.md#setup-for-decentralized-deployment). For previously published versions, see the [license history](https://github.com/spreadsheetimporter/ui5-cc-spreadsheetimporter/blob/main/LICENSE.md).
